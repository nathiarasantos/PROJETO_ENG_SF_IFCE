A manutenção mais provável nos primeiros anos será a manutenção evolutiva,
pois novas necessidades podem surgir conforme a loja utiliza o sistema. Por exemplo, o sistema pode inicialmente controlar apenas entradas e saídas de produtos e, futuramente, receber uma funcionalidade que alerta quando determinado produto estiver com estoque abaixo do limite definido.

Inicialmente, o sistema permite que os funcionários cadastrem produtos, consultem a quantidade disponível e registrem a entrada e saída de mercadorias. Após alguns meses de uso, a loja percebe que alguns produtos acabam sem que os funcionários percebam a tempo, causando problemas nas vendas.

Para solucionar isso, o sistema poderia receber uma nova funcionalidade de alerta de estoque mínimo. O funcionário definiria, que um determinado produto por exemplo deve possuir pelo menos 10 unidades em estoque. Quando a quantidade chegar a 10 ou menos, o sistema exibiria um aviso indicando que é necessário realizar uma reposição.
